## Spotify capture

The DOM exposed an ARIA grid (the native tree called it a table). Mounted rows had `aria-rowindex`: header 1, first track 2. This supports merging virtualized rows by position without losing duplicates.

After observing the grid and attributes, illustrative read-only extraction:

```js
const rows = await spotify.playwright
  .getByRole('grid', {name: sourceName, exact: true}).getByRole('row')
  .evaluateAll(rows => rows
    .filter(r => Number(r.getAttribute('aria-rowindex')) > 1)
    .map(r => ({
      order: Number(r.getAttribute('aria-rowindex')) - 1,
      text: r.innerText,
      links: Array.from(r.querySelectorAll('a')).map(a => ({
        text: a.textContent, href: a.getAttribute('href')
      }))
    })));
```

Scroll the main collection, observe, and merge by order until the displayed count reconciles. Sidebar scrolling is separate. Playing rows can omit their visible ordinal. Extract fields from links/row structure, not fixed newline offsets; text may include album/date/explicit badges. Artist links can contain several comma-separated names.
